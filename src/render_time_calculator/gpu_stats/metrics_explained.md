- **Core clock (MHz)**  
  The core clock is the operating frequency of the GPU’s main processing units, measured in megahertz. It is relevant because higher clock speeds generally allow the GPU to perform more operations per second, directly impacting rendering speed.

- **Memory clock (MHz)**  
  The memory clock is the speed at which the GPU’s memory operates, influencing how quickly data can be read from or written to VRAM. It is relevant because faster memory improves data transfer rates, reducing bottlenecks during rendering.

- **Memory Size (MiB)**  
  Memory size refers to the total amount of VRAM available on the GPU. It is relevant because insufficient memory can limit the size and complexity of scenes that can be rendered efficiently.

- **Memory Bandwidth (GB/s)**  
  Memory bandwidth measures the rate at which data can be transferred between the GPU and its memory. It is relevant because rendering workloads often require moving large amounts of data, making bandwidth a key performance factor.

- **Memory Bus width (bit)**  
  Memory bus width is the number of bits that can be transferred per memory cycle between the GPU and VRAM. It is relevant because wider buses enable higher data throughput, improving overall memory performance.

- **Fillrate MTexels/s**  
  Texture fill rate represents how many texture elements (texels) the GPU can process per second. It is relevant because texture-heavy scenes rely on this capability for efficient rendering.

- **Fillrate MPixels/s**  
  Pixel fill rate indicates how many pixels the GPU can render per second. It is relevant because higher pixel throughput directly affects how quickly final images can be produced.

- **Fab (nm)**  
  Fabrication node refers to the semiconductor manufacturing process size used to build the GPU, measured in nanometers. It is relevant because smaller nodes typically allow for more efficient, faster, and denser chips.

- **Transistors (million)**  
  Transistor count is the total number of transistors on the GPU chip, measured in millions. It is relevant because more transistors generally enable more complex and powerful processing capabilities.

- **Die size (mm)**  
  Die size is the physical area of the GPU chip, measured in square millimeters. It is relevant because larger dies often accommodate more hardware resources, which can correlate with higher performance.
